# Vibes iOS

## Setup 

* Get Xcode 16+
* Get latest iOS SDK (Tested with iOS 18, 26 and 27 as of Septemmber 2026)
- Clone the repo
- Open the floder containing the whole project and navigate to the Vibes (Positve only Social) Folder

### Testing 

 Remember that tests are essential to any codebase, so we encourage you to include tests whenever you modify or add new functionality.

* Product -> Scheme -> Edit Scheme -> Test -> (Pick a test plan) -> (arrow) -> Configurations -> Arguments Passed on Launch
* Hit + and type "UI-TESTING"
